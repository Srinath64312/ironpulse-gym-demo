# Gig 21 Demo — Local Business Landing Page

Demo business: IronPulse Fitness, Hyderabad.

## Customize for a client
Edit `index.html`:
- Business name/logo
- Phone and WhatsApp link
- Services
- Address
- Opening hours
- Email
- Photos/colors

## Deploy
Upload this folder to GitHub, then import the repository into Vercel.
No backend is required for this demo.

## Important
This is a fictional demo. Replace all demo contact details before delivering to a real client.
